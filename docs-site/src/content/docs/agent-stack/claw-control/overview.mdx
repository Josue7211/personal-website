`claw control` is the operator surface for agent work. It should show what agents are doing, what they need, and where intervention is required.

## Role in the stack

`claw control` sits above the runtime pieces. It does not replace memory, secrets, or shell execution; it gives a human a single place to steer them.

## Core surfaces

| Surface | Purpose |
| --- | --- |
| Runs | Active and recent agent tasks. |
| Messages | Status, questions, and decisions. |
| Todos | Work items tied to a run. |
| Missions | Larger goals spanning multiple runs. |
| Homelab actions | Private ops tasks when agent work touches infrastructure. |
