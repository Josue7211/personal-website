Create `src/styles/tokens.css`. All tokens go inside a single `@theme { }` block. This is Tailwind v4 CSS-first configuration — no tailwind.config.js exists.

The `@theme` block automatically:
1. Generates utility classes: `--color-primary` → `bg-primary`, `text-primary`, `border-primary`
2. Exposes the values as CSS custom properties on `:root` for use in arbitrary CSS

Create the file with these exact contents:

```css
/* src/styles/tokens.css */
/* Design tokens — locked per CONTEXT.md D-09 through D-14 */
/* All tokens inside @theme generate both utility classes AND CSS custom properties */

@theme {
  /* ===== Color Tokens ===== */

  /* Accent / Primary (D-09) */
  --color-primary: #a855f7;
  --color-primary-deep: #7c3aed;
  --color-primary-soft: #c4b5fd;
  --color-primary-glow: rgba(168, 85, 247, 0.15);

  /* Surfaces (D-10) */
  --color-bg: #0a0a0a;
  --color-surface-1: #111111;
  --color-surface-2: #1a1a1a;
  --color-surface-3: #222222;

  /* Text (D-11) */
  --color-text: #e4e4e7;
  --color-text-muted: #a1a1aa;
  --color-text-accent: #c4b5fd;

  /* ===== Typography (D-01, D-02, D-03) ===== */
  /* Generates font-display, font-body, font-mono utility classes */
  --font-display: 'Playfair Display', Georgia, serif;
  --font-body: 'Space Grotesk', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', 'Courier New', monospace;

  /* ===== Border Radius (D-14: 2-4px max — sharp, architectural) ===== */
  --radius-sm: 2px;
  --radius: 4px;
}
```

Do NOT create a tailwind.config.js file. Tailwind v4 ignores it. Do NOT add tokens to a `:root` block — the `@theme` block handles both token definition and CSS variable generation.

Do NOT add any border/stroke color tokens — D-12 (No-Line Rule) means structure comes from tonal layering only.

Create `src/styles/global.css`. This file must:
1. Import Tailwind v4 (the `@import "tailwindcss"` line activates the entire Tailwind system)
2. Import tokens.css AFTER the Tailwind import (order matters — Tailwind must process first)
3. Set box-sizing reset
4. Set scroll-behavior: auto (Lenis overrides this in Phase 2)
5. Set body defaults using CSS variables from tokens.css

**IMPORTANT — Pitfall 5 (DocsLayout body background):** Do NOT set `background-color` on `body` here. Instead leave body background unset globally. Each layout will set its own background on its wrapper div. This prevents the near-black body background from bleeding into DocsLayout's clean white/neutral surface.

```css
/* src/styles/global.css */
@import "tailwindcss";
@import "./tokens.css";

/* Box model reset */
*,
*::before,
*::after {
  box-sizing: border-box;
}

/* Scroll behavior — Lenis overrides this to 'smooth' in Phase 2 */
html {
  scroll-behavior: auto;
}

/* Body defaults — background NOT set here; each layout sets its own */
body {
  color: var(--color-text);
  font-family: var(--font-body);
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  margin: 0;
  padding: 0;
}
```
